# ROLAX

Запуск:  `node server.js`  → http://localhost:3000   (нужен только Node 18+, зависимостей нет)

- `public/data.js`   — персонажи, карты, скины, коробки (добавлять новое тут)
- `data/events.json` — ивенты по месяцам ("month": "2026-11"), "*" = всегда
- `data/news.json`   — новости, показываются во вкладке NOTICIAS
- `public/sprites/<id>.png` — рисунок персонажа заменит нарисованную фигуру
- `server.js` — аккаунты, изумруды, коробки, скины, карты игроков, сообщения
- Редактор карт (кнопка MAPAS): рисуешь, пробуешь, сохраняешь, экспортируешь файл/код или отправляешь другому игроку сообщением
- Оплата: заглушка во вкладке "COMPRAR 💎" (сделаем потом)

Все персонажи, карты и скины оригинальные. Без чужих торговых марок/персонажей (Brawl Stars, Roblox, Minecraft, Dragon Ball).
Управление: WASD, мышь+клик, Пробел/ПКМ = супер, E = гаджет. На телефоне: стик слева + кнопки.
